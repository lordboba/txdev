LORDBOBA
Tyler's crowned boba coding companion.

Contains the original pet.json and spritesheet.webp from Tyler's Codex setup.

Setup for Codex installations with custom-pet support:
1. Unzip this download.
2. Copy the lordboba folder into ~/.codex/pets/ (or the pets folder within
   your custom CODEX_HOME). Keep pet.json and spritesheet.webp together.
3. Reopen Codex and select Lordboba in the pet picker.

Back up any existing lordboba folder before replacing it.
Custom-pet availability and picker controls may vary by Codex version.

Spritesheet: 8 columns x 9 rows, 192 x 208 pixels per frame.
